Overview:
This project uses Java to manage employee records with a custom hash table.

Features:
- Stores employee names and identification numbers.
- Uses an array of linked lists to implement a hash table.
- Handles hash collisions using separate chaining.
- Searches for employee records by name.
- Loads employee records from a file and measures search execution time.

Concepts Used:
- Java
- Hash tables
- Linked lists
- Hashing and collision handling
- File input/output
- Object-oriented programming

Purpose:
This project helped me practice implementing data structures and understand how hashing can support searching and organizing records.
